CODEX V6.3 — دليل التشغيل
======================

التشغيل على Windows وVS Code
----------------------------
1) فك ضغط CODEX-V6.zip.
2) افتح مجلد CODEX-PLUS في VS Code من File > Open Folder.
3) افتح index.html.
4) اضغط كليك يمين واختر Open with Live Server.
   إذا لم يكن Live Server مثبتًا، ثبّته من Extensions داخل VS Code.
5) ابدأ من صفحة تسجيل الدخول وأنشئ حسابًا تجريبيًا.

الملفات الأساسية
----------------
- index.html / style.css / app.js: الصفحة الرئيسية.
- login.html / login.css / login.js / auth.js: الحسابات وتسجيل الدخول.
- profile.html / profile.css / profile.js: الملف الشخصي والتقدم.
- course.html / course.css / course.js / course-data.js: الدروس.
- labs.js: التحديات والمعامل العملية.
- playground.html / playground.css / playground.js: محرر HTML وCSS وJavaScript.

مهم تعرفه
---------
- الحسابات محلية على نفس المتصفح والجهاز؛ ليست حسابات سيرفر ولا يوجد تسجيل دخول حقيقي عبر الإنترنت.
- كلمات المرور تُخزّن كقيمة مشتقة باستخدام PBKDF2 داخل المتصفح، لكن هذا لا يجعل النظام بديلًا عن مصادقة خادم آمنة.
- التقدم والنقاط محفوظان في localStorage. استخدم تصدير التقدم من الملف الشخصي للاحتفاظ بنسخة احتياطية.
- لا تمسح بيانات الموقع أو بيانات المتصفح قبل تصدير التقدم.
- الاختبارات النظرية اختيارية، والتحدي العملي هو الذي يكمل الدرس.
- ساحة التجربة تشغّل HTML وCSS وJavaScript فقط، ولا تشغّل Python.
- شهادة الإتمام التي ينشئها الموقع شهادة داخلية غير معتمدة رسميًا.
- محتوى المسارات ما زال تعليميًا تمهيديًا ويحتاج توسعة ومراجعة قبل وصف CODEX بأنها منصة مكتملة أو جاهزة تجاريًا.

ما تم تحسينه في V6
------------------
- جعل فشل حفظ بيانات الحساب يظهر برسالة بدل إظهار نجاح وهمي.
- تحسين عدّ الدروس المكتملة ومنع تكرار احتساب نفس الدرس في الإحصائيات.
- جعل أشرطة التقدم لا تتجاوز 100% حتى مع بيانات قديمة غير سليمة.
- إزالة تفاصيل الإجابة من التلميح حتى لا يكشف الحل.
- الإبقاء على تصميم V5 وملفاته الأساسية دون تغيير جذري.


تحديث V6.3 — مسار CSS
----------------------
- توسعة كورس CSS إلى 16 درسًا تدريجيًا.
- إضافة دروس عن المحددات، الوراثة، Box Model، الخطوط، Display، Flexbox، Grid، الوحدات، Media Queries، الحالات والعناصر الوهمية، المتغيرات، Transitions، Position، الظلال، ومشروع نهائي.
- لكل درس شرح ومثال وتحدٍ عملي واختبار اختياري.
- ما زالت بقية المسارات بحاجة إلى توسعة ومراجعة، ولا تعتبر المنصة مكتملة بعد.
